# What is in this repository

Six things at the top level. Nothing is duplicated.

```
REPORT.pdf                 THE SUBMISSION — 13 pages, everything the
                           assignment asks for, figures included
REPORT.html                the source of REPORT.pdf (figures embedded)
README.md                  the same material in full detail, for reference
USAGE.md                   how to run everything
STRUCTURE.md               this file
LICENSE                    MIT

MATLAB_middle_ear_model/   the MATLAB model (21 .m files + 1 launcher)
web/                       the interactive web simulator
figures/                   the five generated figures
```

## MATLAB_middle_ear_model/ — 21 files

| Group | Files | What they are |
|---|---|---|
| Circuit blocks | `Z_cavity` `Z_eardrum` `Z_ossicles` `Z_joint` `Z_stapes` `Z_cochlea` | one file per subsystem of Fig. 1 |
| Model | `middleEarParams` `middleEarResponse` `combinedEarResponse` `combinedEarIR` | parameters, the ladder, the cascade, the impulse response |
| Inherited, unchanged | `outerEarParams` `outerEarResponse` `outerEarIR` `test_outerEar` | copied byte-identical from the outer-ear assignment |
| Run it | `runAll` `run_middle_ear.command` `combinedEarModel` | one command for everything; the GUI |
| Produce results | `generateCombinedFigures` `runMiddleEarExperiments` `runOtitisMedia` `exportWebReference` | the figures, the experiments, the extension, the web data |
| Tests | `test_vsPaper` `test_middleEar` `test_audioIR` `test_combinedGui` | 4 suites |

## web/ — 18 files

A static site: no framework, no build step, no external dependencies.

| File | What it is |
|---|---|
| `index.html` `css/style.css` | the page and its styling |
| `js/complex.js` `js/outerEar.js` `js/middleEar.js` `js/combined.js` | the physics, ported from MATLAB |
| `js/plot.js` `js/audio.js` `js/diagram.js` | plotting, Web Audio, the clickable circuit map |
| `js/app.js` `js/paramSpecs.js` `js/content.js` `js/experiments.js` | the interface |
| `data/reference.js` `data/reference.json` | parameters and reference responses, generated by MATLAB |
| `data/report.js` | the written experiment report |
| `tools/compare.js` | the offline web-vs-MATLAB check |
| `README.md` | notes on the web build |

Most of the size is `data/reference.*` — 220 kB each, because they carry the
complex responses for 12 scenarios at 96 frequencies used to verify the port.

## figures/

`fig1_outer_ear` `fig2_middle_ear` `fig3_combined` `fig4_experiments`
`fig5_otitis_media` — regenerate them any time with `runAll`.
